PUBLICACIÓN
1. En GitHub, termina de crear un repositorio nuevo llamado por ejemplo TECCHNEX-CAM-SST.
2. Para la primera publicación, puedes marcarlo como Private mientras revisas el contenido; recuerda que GitHub Pages puede tener restricciones según el plan y visibilidad.
3. Descomprime este ZIP en tu computador.
4. Entra en la carpeta TECCHNEX_CAM-SST-06C y selecciona TODO su contenido, incluyendo index.html, app.js, styles.css, data, vendor y templates.
5. Sube los archivos al directorio raíz del repositorio (no subas la carpeta contenedora como un nivel adicional).
6. Confirma los cambios en la rama main.
7. En Settings > Pages, configura Deploy from a branch, rama main y carpeta /(root), y guarda.
8. Espera el despliegue, abre la URL que indique GitHub y prueba las funciones esenciales.

ANTES DE DECLARAR ESTABLE
