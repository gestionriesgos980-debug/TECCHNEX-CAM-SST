# CAM-SST-01A — Matriz de convergencia

## Fuente real
El formato HSEQ suministrado presenta información general, campos adicionales, 50 aspectos evaluados y, por aspecto, hallazgo, calificación y evidencia. El informe final incluye observaciones generales y recomendaciones.

## Reutilizar
- Datos de contexto
- Evaluación por aspectos
- C / NC / NA
- Hallazgo / observación
- Evidencia fotográfica
- Observación general
- Persistencia local

## Adaptar
- Categorías → biblioteca SST
- Hallazgo → gestión
- Recomendación → acción
- Resultado → seguimiento

## Pendiente de validar
- Metodología de evaluación/valoración
- Criterios de priorización
- Jerarquía y definición de controles que use el área
- Estructura definitiva del informe
